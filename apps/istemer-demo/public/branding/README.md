# i-STEMer demo branding

These public assets are used only by the i-STEMer demo tenant shell:

- `istemer-logo.png` — sourced from the public i-STEMer website logo at
  <https://istemer.org/wp-content/uploads/2025/12/i-stermer-w-1024x295.png>.
- `hadeer-avatar.jpeg` — sourced from the public team image at
  <https://istemer.org/wp-content/uploads/2025/12/hadeer-1--659x1024.jpeg>.

The Facebook and Instagram profile image URLs are signed and can expire, so the
app does not hardcode them. If the owner supplies a different approved avatar,
replace the local file and update this source note. The shell keeps the demo
indicator and fixture provenance visible regardless of these assets.
